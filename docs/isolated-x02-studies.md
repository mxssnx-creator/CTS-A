# Isolated x02 studies

`CTS_A_CLIENT_NAMESPACE` optionally separates concurrent CTS-A instances on the same connection. Use one stable value of one to eight letters/digits and retain it across restart with the same private output files. An instance with a namespace recognizes only its own connection/namespace client identities. Unset keeps the original project/connection prefixes. This never authorizes adoption of an unrelated desk.

`npm run test:execution-offline` runs connection ownership, signing, parsing and control-quantity checks with external Node transports blocked and exchange credential variables removed before imports. The ticker tests use in-memory fixtures for both network identities. Authenticated VST studies are separate from this functional suite.
